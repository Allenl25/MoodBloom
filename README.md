## Project

Project details follow. 

### Project Name
MoodBloom

### Project Description  
MoodBloom is a mental wellness web application designed to help users track their daily moods, write journal entries, view emotional trends over time, access wellness resources, and connect with others through a community page. The goal of the application is to provide a simple and user friendly platform that encourages self reflection and positive mental wellness habits.

## Set Up and Installation

Details on how to set up the project follow.

1. Clone the repository from GitHub
2. Open the project folder in Visual Studio Code.
3. Make sure Java 17 is installed on your computer.
4. Open a terminal in the project folder and build the project:
.\mvnw.cmd clean install

5. Run the Spring Boot application:
.\mvnw.cmd spring-boot

6. Open a web browser and navigate to:
http://localhost:8080

Note: Database functionality is currently disabled to allow the team to focus on building application features and user interface components first. A shared database may be added later in the project.
